# Assets

Photos, diagrams, and logos for the U-SCAR project — drop image files in here and reference them from any README with standard markdown:

```markdown
![description](../assets/your-image.png)
```

Suggested contents:
- Hardware photos (drone, Jetson, camera, gimbal, wiring)
- Diagrams (wiring/system architecture)
- Project logo

Keep individual images reasonably sized (compress large photos before committing) so the repo doesn't balloon.
