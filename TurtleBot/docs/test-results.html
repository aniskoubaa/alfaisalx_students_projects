08

How to add results

  1. Open this file (TurtleBot/docs/test-results.html) in a text editor.
  2. Copy a row in the right table, remove class="ph", fill in the cells. Status chips: chip ok done, chip bad aborted, chip warn stopped or skipped, chip todo pending.
  3. Take the position and heading errors from the program's last lines (error: position ... cm, heading ... deg).
  4. Update the summary tiles, and the status block in examples/README.md.
  5. Never paste passwords or keys into logs or this page.
