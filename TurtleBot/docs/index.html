AlfaisalX lab · TurtleBot 4 Standard

TurtleBot 4 documentation

Everything written about the lab's TurtleBot 4 (Raspberry Pi 4 on an iRobot Create 3 base, Ubuntu 24.04, ROS 2 Jazzy). Log in from any computer with ssh ubuntu@turtlebot4.local, or with the address on the robot's display. Passwords are not stored here; ask the lab maintainer.
