AlfaisalX lab · TurtleBot 4 Standard

TurtleBot 4 documentation

Everything written about the lab's TurtleBot 4 (Raspberry Pi 4 on an iRobot Create 3 base, Ubuntu 24.04, ROS 2 Jazzy). Log in from any computer with ssh ubuntu@turtlebot4.local, or with the address on the robot's display. Passwords are not stored here; ask the lab maintainer.

tools/connect/

Connect tool not yet run on the robot

TurtleBotConnect.exe (Windows 10 or 11, no installation) and connect-turtlebot.sh (macOS, Linux), version 1.1.0. A menu to connect, find the robot, set up key login, show status, open VS Code, add an SSH shortcut, stop the motion programs in an emergency, copy a file and fix "host key changed". It only talks to a device with the lab robot's host key. The exe is unsigned: SmartScreen asks once (More info, Run anyway), or build it from source.
