Task: Connect the TurtleBot 4 to the university Wi-Fi, and set up SSH access from a laptop

Background:
- The robot's Raspberry Pi starts in Access Point mode: it creates its own Wi-Fi network "Turtlebot4" (factory default, robot address 10.42.0.1).
- With one Wi-Fi card, joining "Turtlebot4" drops the laptop's internet. Fix used here: a second USB Wi-Fi adapter (Realtek 8811CU) so the built-in card stays on the university network and the USB adapter joins the robot.
- No passwords or personal credentials are written in this file (the repo is public).
