# General Tasks

Repo-wide notes on tasks and troubleshooting — especially things that were tried and *didn't* work, so nobody re-debugs the same dead end. One file per task/issue.

Suggested format for a new entry (plain text or markdown, either is fine):

```
Task: <short title>

Tried:
- What you attempted and where the instructions came from.

Result:
- What happened (error message, behavior, etc.).

Next steps / ideas:
- What to try next, if known.
```
