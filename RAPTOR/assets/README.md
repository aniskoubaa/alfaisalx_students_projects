# Assets

Photos, diagrams, and logos for the RAPTOR project — drop image files in here and reference them from any README with standard markdown:

```markdown
![description](../assets/your-image.png)
```

Current contents:
- `photos/` — photos of the build. The wiring map and build view in `docs/` take their
  component positions from these.
  - `airframe-side.jpeg` — the X500 V2 from the side: legs, arms, stack height.
  - `airframe-three-quarter.jpeg` — three-quarter view of the whole airframe.
  - `airframe-top.jpeg` — looking down on the frame: arm layout and top plate.
  - `top-deck-pixhawk-6c-r86c.jpeg` — the top deck: Pixhawk 6C and the R86C receiver.
  - `front-a8-mini-gimbal.jpeg` — the front, with the SIYI A8 mini gimbal camera.

Suggested contents:
- Hardware photos (drone, Jetson, camera, gimbal, wiring)
- Diagrams (wiring/system architecture)
- Project logo

Keep individual images reasonably sized (compress large photos before committing) so the repo doesn't balloon.
