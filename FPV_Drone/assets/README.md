# Assets

Photos and diagrams for the FPV_Drone project. Reference them from any README with standard
markdown:

```markdown
![description](../assets/photos/your-image.jpeg)
```

Current contents:
- `photos/` — photos of the build, taken 22 October 2026.
  - `airframe-top.jpeg` — from above: arm layout, the 1500 mAh 4S battery, the GPS puck.
  - `airframe-bottom-telemetry-radio.jpeg` — from below: the 433 MHz telemetry radio and its antenna.
  - `side-flight-controller-px4-ports.jpeg` — the Pixhawk 6C Mini's USB-C, FMU Debug, I2C and GPS2 side.
  - `side-flight-controller-ardupilot-ports.jpeg` — its RSSI, DSM and SD-card side.
  - `end-gps-and-receiver-antennas.jpeg` — end-on, with the GPS puck and the two receiver antenna leads.

Keep individual images reasonably sized (compress large photos before committing) so the repo doesn't balloon.
