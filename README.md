# AlfaisalX Student Projects

This repository is a shared home for student projects at AlfaisalX. Each project lives in its own top-level folder.

## Projects

- [`U-SCAR/`](./U-SCAR) — Quadcopter UAV project: drone platform with camera/gimbal integration and a Jetson Orin Nano-based AI vision pipeline for object detection and tracking.

More projects will be added here over time, each in its own folder with its own README.

- [`General Tasks/`](./General%20Tasks) — repo-wide task notes and troubleshooting log (things tried, including failed attempts).
